AccessLens | App Map (draft)

Independently prepared code orientation, not evidence of official Devpost skill completion.

1. Input

index.html hosts upload/textarea controls; app.js registers buttons, reads file text, invalidates stale results.

2. Check

analyzer.js → analyzeHTML() parses HTML locally and creates structured findings from five heuristics. To understand one path, follow img:not([alt]) to the image-alt finding.

3. Present

app.js → render() creates issue cards with textContent, which prevents copied user markup from executing in the app.

4. Export

analyzer.js → markdownReport() produces text; app.js → exportReport() turns it into a browser download, leaving original HTML intact.

5. Verify

tests/tests.js covers rule behavior. tests/node-tests.cjs supports a dependency-free test double; tests/run-tests.html uses native browser DOMParser.

# AccessLens | Scope (DRAFT)

## Who and what
A small-site maker wants practical, explainable feedback before publishing hand-authored HTML. Existing large-scale scanners may overwhelm a beginner. AccessLens keeps attention on five static patterns where a fix can be described clearly.

## One-sentence kernel
Turn objective HTML accessibility patterns into pinpointed, copy-ready examples without inventing a numerical accessibility score.

## In-scope proof of concept
- Paste HTML or load a local `.html` file without uploading it.
- Run checks for missing image alt attributes, empty links, unlabeled form fields, duplicate IDs and heading order.
- Show affected element excerpts, approximate location, workflow priority, brief explanation and suggested repair.
- Filter findings by priority and export a human-readable Markdown report.
- Demonstrate the five expected findings on a deliberately flawed garden-club page and fewer findings after a corrected example.

## Out-of-scope
No full WCAG certification, remote site crawl, browser extension, automated alteration of owner files, published deployment, third-party integration, CSS contrast measurement, dynamic runtime tests, accounts, payments, analytics or AI-generated scoring.

## Definition of working
A freshly extracted ZIP opens locally, makes its two sample checks, generates suggestions, and exports a report with no external service. Automated tests demonstrate the five checks plus invalid inputs. Browser verification should be recorded, not assumed.
